# Why the scrum rules exist

The incidents behind the rules in `SKILL.md`. Read this only when a rule is
being changed or questioned.

## A project link is a complete instruction

The failure the skill was written for: a project with twelve tickets where the
agent read three, asked "where do I start?", asked which repo, asked whether a
blocker was real, and Elias spent the session answering questions that were
already answered in a Postplan document nobody linked.

## The description is the whole idea

Elias named it on 19 sep: tickets whose description referenced decisions ("I
said this, I said that") instead of explaining the thing. Whoever opened one
knew where the idea came from and not what to build, so they invented or they
asked.

## Unplanned requests

On 19 September 2026 Elias chose immediate recording and impact-based triage
for requests that arrive outside the weekly plan.
